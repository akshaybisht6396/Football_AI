A computer vision-based pipeline designed to extract meaningful insights from football match footage. This system leverages deep learning for object detection and tracking to automate player statistics and tactical analysis.

Key Features
Player & Ball Detection: Utilizes YOLO (You Only Look Once) for high-speed, real-time identification of players, referees, and the ball.

Tactical Tracking: Persistent tracking of entities across frames to monitor movement patterns and positioning.

Action Recognition: (Optional/Planned) Identification of specific events like passes, shots, or tackles.

Team Classification: Automated grouping of players based on jersey color analysis using OpenCV.
